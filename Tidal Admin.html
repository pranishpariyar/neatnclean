Run this site locally

Start the Node server from the project folder:

npm start

Homepage: http://127.0.0.1:3000/nac.html
Admin:    http://127.0.0.1:3000/Tidal%20Admin.html

The first admin account can only be created from this computer. The database is stored in data/neat-clean.sqlite. Keep the server on localhost unless it is deployed behind HTTPS with production access controls.
